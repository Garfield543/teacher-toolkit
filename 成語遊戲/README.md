# 成語大冒險 (成語遊戲) v2.0 🐾

適合低年級學生的互動式成語學習與闖關遊戲。

## 🌟 特色功能

1. **三輯題庫與全輯挑戰**：
   - 📗 **第一輯 (W1.2)**：一朝一夕、一落千丈、一舉兩得、七零八落、人小鬼大、力挽狂瀾、十惡不赦、三頭六臂、亡羊補牢、千載難逢。
   - 📘 **第二輯 (W3.4)**：口不擇言、大逆不道、大顯身手、寸步難行、山窮水盡、不求上進、不屈不撓、不期而遇、予取予求、允文允武。
   - 📙 **第三輯 (W5.6)**：分門別類、天真爛漫、天經地義、心甘情願、心血來潮、心曠神怡、手忙腳亂、水火不容、水落石出、火冒三丈。
   - 🌟 **全輯挑戰**：30 個成語隨機綜合考驗。
2. **六大動物夥伴**：小兔 🐰、小熊 🐻、小狐 🦊、小貓熊 🐼、小貓 🐱、小松鼠 🐿️
3. **兩大遊戲模式**：
   - 🌱 **練習版**：自選單一玩法，完成一輪，反覆精熟。
   - 🏆 **挑戰版**：四種玩法隨機綜合闖關，具備即時計時、星級評等（滿分 5 顆星）與完成時間紀錄。
4. **四大核心玩法**：
   - 🎈 **選一選**（多選題）：看語意找出正確成語。
   - 🧩 **拼一拼**（字塊重組）：點選字塊組成四字成語，支援退回與重新排列。
   - 🔗 **配一配**（連線配對）：4 組成語與白話語意卡片雙向配對。
   - 🔍 **成語偵探**（情境閱讀）：閱讀生活化情境故事，找出最契合的成語。
5. **Web Audio 音效與動畫系統**：
   - 內建無版權即時合成音效（答對叮咚、答錯低音、星星琶音、通關號角、翻牌點擊聲）。
   - 頂部 🔊/🔇 一鍵切換靜音，偏好儲存於 localStorage。
   - 答對彩色紙花（Confetti Canvas）與 3D 翻牌脈衝動效。
6. **Firebase 班級即時排行榜與進度牆**：
   - 1~40 號免打字點選座號（亦可跳過為訪客）。
   - 即時上傳成績至 Firestore（去識別化，只記錄座號）。
   - 支援「🏆 挑戰英雄榜」與「📊 全班 1~40 號即時進度牆」。
7. **平板與手機版面雙模式**：
   - 針對平板大觸控區優化，防誤觸放大 (`touch-action: manipulation`)。
   - 頂部提供 💻 平板模式 / 📱 手機模式一鍵切換。
