# 成語大冒險 (成語遊戲) v3.0 🐾

適合低年級學生的互動式成語學習與闖關遊戲。

## 🌟 特色功能

1. **十輯題庫與兩組全輯挑戰**（共 100 個成語）：
   - 📗 **第一輯 (W1.2)**：一朝一夕、一落千丈、一舉兩得、七零八落、人小鬼大、力挽狂瀾、十惡不赦、三頭六臂、亡羊補牢、千載難逢。
   - 📘 **第二輯 (W3.4)**：口不擇言、大逆不道、大顯身手、寸步難行、山窮水盡、不求上進、不屈不撓、不期而遇、予取予求、允文允武。
   - 📙 **第三輯 (W5.6)**：分門別類、天真爛漫、天經地義、心甘情願、心血來潮、心曠神怡、手忙腳亂、水火不容、水落石出、火冒三丈。
   - 📕 **第四輯 (W7.8)**：仗勢欺人、出人意表、出人頭地、半途而廢、失而復得、失魂落魄、任勞任怨、光宗耀祖、光明磊落、各顯神通。
   - 📓 **第五輯 (W9.10)**：同病相憐、名列前茅、回心轉意、宅心仁厚、守株待兔、有恃無恐、羊入虎口、老奸巨猾、老當益壯、自告奮勇。
   - 📒 **第六輯 (W11.12)**：自相殘殺、自討沒趣、衣冠楚楚、似懂非懂、吹毛求疵、快馬加鞭、我行我素、改邪歸正、束手無策、良師益友。
   - 📔 **第七輯 (W13.14)**：和藹可親、所向無敵、易如反掌、欣欣向榮、盲人摸象、直接了當、空前絕後、虎頭蛇尾、門庭若市、信口開河。
   - 📑 **第八輯 (W15.16)**：怨天尤人、指鹿為馬、眉開眼笑、迫不及待、倒吃甘蔗、弱不禁風、海底撈針、狼狽為奸、偷雞摸狗、執迷不悟。
   - 🔖 **第九輯 (W17.18)**：情同手足、理直氣壯、盛氣凌人、雪中送炭、喪盡天良、單槍匹馬、提心吊膽、朝三暮四、無中生有、無動於衷。
   - 🏅 **第十輯 (W19.20)**：痛改前非、愚公移山、愛屋及烏、當仁不讓、當頭棒喝、腳踏實地、道聽塗說、隔牆有耳、寧缺勿濫、截長補短。
   - 🌟 **全輯挑戰 (1–5輯)**：第一至五輯共 50 個成語隨機綜合考驗。
   - 🌟 **全輯挑戰 (6–10輯)**：第六至十輯共 50 個成語隨機綜合考驗。
2. **六大動物夥伴**：小兔 🐰、小熊 🐻、小狐 🦊、小貓熊 🐼、小貓 🐱、小松鼠 🐿️
3. **兩大遊戲模式**：
   - 🌱 **練習版**：自選單一玩法；配一配單輯 5 回、全輯 6 回，每回 4 組；其他一般練習每輪 10 題，打地鼠限時 30 秒。
   - 🏆 **挑戰版**：每輪 10 關；第一至五輯混合原有 4 種玩法，第六至十輯另加入 3 題「用對了嗎」，具備即時計時、星級評等（滿分 5 顆星）與完成時間紀錄。
4. **7 種玩法與團體模式**（依題庫開放；品格分類箱與打地鼠不納入綜合挑戰版）：
   - 🎈 **選一選**（多選題）：看語意找出正確成語。
   - 🧩 **拼一拼**（字塊重組）：點選字塊組成四字成語，支援退回與重新排列。
   - 🔗 **配一配**（連線配對）：4 組成語與白話語意卡片雙向配對。
   - 🔍 **成語偵探**（情境閱讀）：閱讀生活化情境故事，找出最契合的成語。
   - ⭕❌ **用對了嗎**（第六～十輯專屬）：每回合一句話，判斷成語用得對不對；答完顯示原因與正確用法。練習版 10 題（5 對 5 錯），挑戰版綜合闖關含 3 題。
   - 📦 **品格分類箱**（僅「第六～十輯全輯挑戰」題庫）：成語卡出現後，選擇放進 👍 值得學習 或 👎 需要改進；答完顯示成語意思。目前收錄已標記分類的 28 個成語（分類仍待本次教師複核）（11 個 👍、17 個 👎），每回合 10 張（5 對 5）。
   - 🐹 **打地鼠：成語出洞**（第六～十輯專屬）：上方顯示白話意思，3×3 的洞裡冒出 4 個成語，限時 30 秒敲出正確的；連續答對有連擊加分（每次 10 分起，連擊最多加到 20 分），敲錯不扣分只中斷連擊。
   - 👥 **團體模式**（第六～十輯專屬）：2～4 隊（動物隊名）輪流比賽，適合大電視全班一起玩或在家和家人玩。可選「用對了嗎」（12 題，答對得 1 分）、「品格分類箱」（12 題，限全輯題庫）、「打地鼠」（每隊限時 30 秒，分數高者勝）。結束顯示排名，同分並列。
5. **成語圖鑑**（第一～十輯共 100 個成語）：
   - 每輯一張成語卡，卡面有 10 個小格對應該輯的 10 個成語。一個成語答對 2 次就「學會」，在卡上蓋章（顯示 emoji 與成語）。
   - 卡片依學會數量升級：3 個點亮、6 個銀邊、10 個全部學會是金邊（★ 星數與標籤同步升級）。
   - 練習版、挑戰版、四種舊玩法與新玩法（用對了嗎、品格分類箱、打地鼠）答對都會累積；團體模式不累積。
   - 點小格可看成語意思、造句（學會後才顯示）；未學會的顯示還差幾次與小提示。
   - 學會新成語、卡片升級時會跳出提示並有慶祝動畫。入口在頂端列的 📖。
   - **綁座號同步**：選了座號，圖鑑會同步到 Firebase 集合 `idiom_album`（文件 `seat-07` 這種格式，內容為 `seat`、`counts`、`updatedAt`），在學校和家裡用同一個座號就看到同一本；訪客只存在該裝置。同步失敗時進度仍會先存在本機，圖鑑頁會顯示提醒。
   - 注意：Firestore 規則需允許讀寫 `idiom_album`；座號沒有密碼，多個班共用同一連結時同座號會共用圖鑑。
6. **Web Audio 音效與動畫系統**：
   - 內建無版權即時合成音效（答對叮咚、答錯低音、星星琶音、通關號角、翻牌點擊聲）。
   - 頂部 🔊/🔇 一鍵切換靜音，偏好儲存於 localStorage。
   - 答對彩色紙花（Confetti Canvas）與 3D 翻牌脈衝動效。
7. **Firebase 班級即時排行榜與進度牆**：
   - 1~30 號免打字點選座號（亦可跳過為訪客）。
   - 即時上傳成績至 Firestore（去識別化，只記錄座號）。
   - 支援「🏆 挑戰英雄榜」與「📊 全班 1~30 號即時進度牆」。
8. **平板與手機版面雙模式**：
   - 針對平板大觸控區優化，防誤觸放大 (`touch-action: manipulation`)。
   - 頂部提供 💻 平板模式 / 📱 手機模式一鍵切換。

## 🗂️ 題庫欄位規格

每個成語在 `index.html` 的 `idiomLibraries[輯數]` 中是一筆物件：

| 欄位 | 用途 |
|------|------|
| `id` | 成語拼音（全題庫不可重複） |
| `idiom` | 四字成語 |
| `zhuyin` | 成語注音 |
| `meaning` | 白話意思（「選一選」題幹、「配一配」右側卡片） |
| `choiceZhuyin` | `meaning` 的注音，結尾接「是哪一個成語？」 |
| `scene` | 生活情境（「成語偵探」題幹，不可直接出現成語） |
| `sceneZhuyin` | `scene` 的注音 |
| `hint` | 小提示（不可洩漏答案） |
| `example` | 聯絡簿造句（含該成語）；也是「用對了嗎」的正確句 |
| `exampleZhuyin` | `example` 的注音 |
| `wrong` | 「用對了嗎」的錯誤句（僅第六～十輯） |
| `wrongZhuyin` | `wrong` 的注音 |
| `wrongWhy` | 錯誤句的原因說明 |
| `wrongWhyZhuyin` | `wrongWhy` 的注音 |
| `trait` | 品格分類：`good`（值得學習）或 `bad`（需要改進）；沒有此欄位的成語不放進「品格分類箱」 |
| `traitPhrase` | 分類卡上顯示的一行短白話 |
| `traitPhraseZhuyin` | `traitPhrase` 的注音 |

第六～十輯的題庫內容整理自 `W11_12成語.docx` ～ `W19_20成語.docx`，注音為程式產生後以台灣讀音校對，建議教師上線前再抽查。
