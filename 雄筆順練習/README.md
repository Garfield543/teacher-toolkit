# 雄筆順練習模組 (Stroke Order Practice)

本模組整合雄老師 **HTML5 FUN 生字筆順練習工具** 與 **教育部國字標準字體筆順學習網**，提供各版本各年級之課堂生字筆順快速導覽與練習。

---

## ⚙️ 雄筆順練習預設設定規範（已配置）
依課堂教學最佳實踐，每課雄筆順掃描練習預設開啟以下功能：
- ✅ **顯示筆順序號** (`number=1` / `enableShowStrokeNumber=1`)
- ✅ **顯示提示點** (`track=1` / `enableShowHintPoints=1`)
- ✅ **提示下一筆順** (`hint=1` / `enableShowHint=1`)
- ✅ **播放語音** (`sound=1` / `enableSound=1`)
