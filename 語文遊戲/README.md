# 語文遊戲 — 的得大挑戰 🎒👩‍🏫

專為國小低年級學生設計的「的」「得」語法辨析互動闖關遊戲。

## 🌟 教學核心概念

1. **🎒「的」百寶袋法（名詞/物品/擁有）**：
   - 像背包一樣裝著各種東西，後面接的是**人、事、物（名詞）**。
   - 例句：`我的書包`、`紅紅的蘋果`、`跑得快的跑車`。
   - 口訣：**「百寶袋裝東西，後面是物品就選『的』！」**
2. **👩‍🏫「得」打分數小老師（動詞後程度評價）**：
   - 像小老師在幫動作打分數，前面是**動作（動詞）**，後面是**表現得如何（程度）**。
   - 例句：`跑得真快`、`跳得很高`、`唱得很好聽`。
   - 口訣：**「小老師打分數，動作表現好壞就選『得』！」**
3. **💡 特殊與固定詞用法**：
   - 副詞修飾動作：`輕輕的踢`、`慢慢的走`、`悄悄的說`。
   - 固定詞組：`覺得`、`變得`、`記得`、`捨不得`。

## 🎮 遊戲特色

- 📖 **教學模式**：圖像化「百寶袋 vs 打分數小老師」規則口訣卡，初學者隨時複習。
- 🏆 **競速挑戰模式**：
  - 每輪隨機抽取 20 題（海量題庫池隨機洗牌，每次玩都不同）。
  - 彩虹倒數計時條（每題 8 秒），考驗直覺與反應。
  - 精確競速計分：`答對基礎分 100 分 + 毫秒級速度加分（最高 220 分/題）`。
  - 答錯即時教學回饋（手動下一題，給予充足閱讀與學習時間）。
- 🔊 **Web Audio 專屬音效引擎**：
  - 答對：清脆輕快的 **E5-C5-E5-C5 四連音**（叮咚叮咚）。
  - 答錯：低沉遺憾感的 **「喔喔（Uh-oh）」雙音節** (A3 降至 F3)。
  - 通關號角、星星獲得音效與彩色紙花動效。
- ☁️ **Firebase 班級即時排行榜與進度牆**：
  - 1~30 號座號免打字點選，支援訪客遊玩。
  - 結算後自由選擇是否上傳座號與戰績。
  - 支援「🏆 競速英雄榜」與「📊 班級 1~30 號即時進度牆」。
- 📱 **跨裝置自適應（Mobile & Tablet）**：
  - 支援大螢幕平板與直/橫式手機，超大點擊觸控區，防誤觸放大。
