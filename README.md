# teacher-toolkit 🧰

老師班級工具箱總專案 — 專為國小教學設計的互動遊戲與實用工具集。

## 🛠️ 工具清單

1. **[成語遊戲 (成語大冒險 v2.0)](./成語遊戲/)** 🐾
   - 適合低年級學生的互動式成語學習與闖關遊戲。
   - 包含三輯題庫切換、4 種玩法（選一選、拼一拼、配一配、成語偵探）、Web Audio 音效、Firebase 班級排行榜與 1~30 號進度牆。
   - 線上體驗：[https://garfield543.github.io/teacher-toolkit/成語遊戲/](https://garfield543.github.io/teacher-toolkit/%E6%88%90%E8%AA%9E%E9%81%8A%E6%88%B2/)

2. **[語文遊戲 (的得大挑戰)](./語文遊戲/)** 🎒👩‍🏫
   - 專為國小低年級設計的「的」「得」語法辨析互動遊戲。
   - 結合「百寶袋法」與「打分數小老師法」，內建 80+ 題精選隨機題庫、8 秒競速計時、叮咚叮咚音效與 Firebase 班級即時進度牆。
   - 線上體驗：[https://garfield543.github.io/teacher-toolkit/語文遊戲/](https://garfield543.github.io/teacher-toolkit/%E8%AA%9E%E6%96%87%E9%81%8A%E6%88%B2/)
