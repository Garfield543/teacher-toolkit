## 🌟 教學核心口訣與二分法

教導低年級孩子時，避免抽象文法，採用**「動作 vs 創意」**具體二分法：

### 1. 🖐️ 動手「做」（動作／體力／具體物品／身分）
- **口訣**：「**做事要認真，手腳動一動！**」
- **想像**：雙手在活動、要花力氣、做出摸得到的具體物品。
- **生活範例**：
  - 體力與家事：做功課、做家事、做飯、做運動、做體操
  - 具體製作物品：做手工、做衣服、做麵包、做蛋糕、做模型、做卡片
  - 擔任身分與關係：做朋友、做人、做事、做官、做主、做生意

### 2. 💡 動腦「作」（創作／動腦／文學藝術／固定名詞）
- **口訣**：「**作品很精彩，腦袋轉一轉！**」
- **想像**：大腦像變魔術一樣，動腦發想出新的作品或抽象心理狀態。
- **生活範例**：
  - 文學與藝術：作文、作家、作品、寫作、著作、作曲、作詩、作畫
  - 抽象發想與狀態：創作、製作（策劃節目/影片）、作夢、振作、作戰
  - 固定詞組：工作、合作、作業、動作、作用、作證、佳作、自作聰明

## 🔍 魔法小偵探：常見容易搞混的詞彙

| 比較組 | 動手「做」 | 動腦「作」 | 辨析關鍵 |
| :--- | :--- | :--- | :--- |
| **勞動 vs 職業** | **做工**（出體力搬磚流汗） | **工作**（固定的職業與事業） | 具體體力動作選「做」；固定名詞選「作」 |
| **美勞 vs 企劃** | **做手工**（剪貼撕黏美勞） | **製作**（企劃構思並完成影音/節目） | 動手勞作用「做」；動腦策劃用「作」 |
| **具體物 vs 藝術** | **做衣服**（親手剪裁縫製） | **作畫／作詩**（動腦靈感創作） | 縫製具體物品用「做」；文藝發想用「作」 |

## 🎮 遊戲核心規格（符合 classroom-game-builder 四大標準）

1. 🔤 **注音開關輔助（Ruby Annotation）**：
   - 頂部導覽列提供「🔤 注音：開 / 關」一鍵切換，內建 localStorage 偏好記憶。
   - 開啟時以教科書標準 Ruby 標註漢字上方注音符號，關閉時回歸純文字大字排版。
2. 📱 **三端自適應排版（電腦／平板／手機）**：
   - 超大雙選按鈕（左邊 🖐️【做】、右邊 💡【作】）。
   - 支援電腦鍵盤快捷鍵（← / 1 選「做」，→ / 2 選「作」，Space / Enter 下一題）。
   - 鎖定 100dvh 與 	ouch-action: manipulation，消除連續點擊延遲與誤觸放大。
3. 🔊 **Web Audio 專屬即時合成音效**：
   - 答對：清脆輕快的 **E5-C5-E5-C5 四連音**（叮咚叮咚）。
   - 答錯：低沉遺憾感的 **「喔喔（Uh-oh）」雙音節**（A3 降至 F3）。
   - 通關號角、星星獲得音效與彩色紙花（Canvas Confetti）。
4. ☁️ **Firebase 班級即時排行榜與 1~30 號進度牆**：
   - 1~30 號座號免打字點選，支援訪客遊玩。
   - 結算後自動即時同步 Firestore 雲端資料庫。
   - 支援「🏆 競速英雄榜 (Top 10)」與「📊 班級 1~30 號即時進度牆」。
